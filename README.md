# Auto-complete and auto-correct

Demo of LLM spell checking, auto-correct, inline completion and a Polish button, in English and Arabic.

**Try it:** https://nikolaimaslak.github.io/SpellCheckingPrototype/

Paste an OpenAI API key in the settings (kept in memory only, not saved).

## Run locally

Needs Node.js 23.6+ and a current Chrome or Edge.

```sh
npm install
npm run dev
```

Open http://localhost:5173/. `CLAUDE.md` describes the code layout.
