# Auto-completion and auto-correct demo

Demo of LLM spell checking, auto-correct, and inline auto-completion, in English and Arabic.

**Try it:** https://nikolaimaslak.github.io/SpellCheckingPrototype/

Paste an OpenAI API key at the top of the page (kept in memory only, not saved).

## Run locally

Needs Node.js 23.6+ and a current Chrome or Edge.

```sh
npm install
npm run dev
```

Open http://localhost:5173/. `CLAUDE.md` describes the code layout.
