# План: демо на React + Tailwind

Цель: минимальная страница, на которой видно, как работают три алгоритма: исправление слов, варианты замены и подсказка автодополнения. Плюс Polish.

## Фронтенд

- Переписать UI на React + Tailwind: компоненты, хуки, отдельные файлы.
- Логика без UI (проверка слов, `decide`, токенизатор, клиенты сервера, diff для Polish, настройки) остаётся в обычных модулях вне компонентов и хуков. Компоненты и хуки только вызывают её.

## Убрать

- Политику админа и выбор агента: `agentMayLower`, `preference`, агент, `teams` / `users` / `listed`.
- Телеметрию на сервер и счётчик событий.
- Откат автозамены по Backspace (`backspaceRevert`).

## Изменить

- **Лог событий**: вместо телеметрии `<pre>` со скроллом на странице, в нём JSON каждого события (как консоль).
- **Ctrl/Cmd+Z**: работает нативно. Все программные изменения (автозамена, выбор варианта, принятие подсказки, Polish) вносятся как ввод пользователя, одним шагом отмены. Сейчас это уже так через `execCommand('insertText')`; проверить Polish с несколькими правками (сейчас каждая правка отдельный шаг отмены).
- **Mode** (`off` / `suggest` / `auto`) разбить на два чекбокса: «Проверка орфографии» и «Автозамена» (вторая доступна только при включённой первой).
- **Auto-replace confidence**: радиокнопки `list` / `list-and-rule`.

## Настройки

Все поля показываются предзаполненными значениями по умолчанию. Изменения сохраняются в `localStorage`. Кнопка **Reset** возвращает значения по умолчанию.

- Проверка орфографии: вкл/выкл.
- Автозамена: вкл/выкл.
- Auto-replace confidence: `list` / `list-and-rule`.
- Языки: `en`, `ar`.
- Словарь компании (`customDictionary`).
- Автодополнение: вкл/выкл.
- Источники для автодополнения: просто текстовые поля вместо чекбоксов и моков на сервере.
  - «Готовые ответы»: textarea, предзаполнена из `server/data/canned.json`, один ответ на строку.
  - «База знаний»: textarea, предзаполнена из `server/data/kb.json`.
  - Переписка берётся из демо-чата, как сейчас.
  - Тексты уходят в запросе `/v1/complete`; сервер ищет в них подходящее (`retrieve`, `retrieve_kb`) вместо чтения своих файлов. Пустое поле = источник выключен.
- Polish: вкл/выкл.
